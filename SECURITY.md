# Security policy

mise-brew deletes files (uninstall, cleanup, cask `zap`) and edits your mise
config, so bugs that could remove the wrong thing are treated as security issues.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/rubnogueira/mise-brew/security/advisories/new)
rather than a public issue. Include the command you ran, your OS, `brew config`
output (it masks tokens) and what was affected.

Only the latest release is supported.
